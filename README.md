# Data-Science-Assignment-1

This project contains solutions for three levels of Python tasks:

- Level 1: Reverse a string
- Level 2: Largest number in a list
- Level 3: CLI-based calculator

  
1. Reverse a String
Description

This program takes a string input from the user and returns the reversed version of that string.

How It Works
Accepts input from the user
Uses slicing ([::-1]) or a loop to reverse the string
Prints the reversed string

2. Find the Largest Number in a List
Description

This program finds and displays the largest number from a list of numbers.

How It Works
Takes a list of numbers (either predefined or user input)
Uses the built-in max() function or a loop
Outputs the largest number

3. CLI-Based Calculator
Description

A simple command-line calculator that performs basic arithmetic operations.

Features
Addition
Subtraction
Multiplication
Division
How It Works
Prompts user to choose an operation
Takes two numbers as input
Performs the selected operation
Displays the result
